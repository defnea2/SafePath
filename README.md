# SafePath
A data-driven routing system that identifies safer walking paths using Boston public streetlight data. I worked on the geospatial model and route optimization, with ight density and path connectivity to compute safer routes; won 1st place in BU’s DS+X Hackathon FirstTrack Path.Team:Defne Akkan,Miriam Dulin,Sergio Luis Guillin Valencia,Manya Katiyar
